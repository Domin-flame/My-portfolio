# Bediguile Ryan — Portfolio

Personal developer portfolio built with HTML, CSS and vanilla JavaScript.

## Features
- Bilingual EN / FR toggle
- Dark mode (auto + manual toggle)
- Animated skill bars and counters
- Dynamic blog articles from WordPress (dominicblog.me)
- Fully responsive (mobile, tablet, desktop)

## Structure
```
├── Portfolio.html       # Main HTML
├── style3.css           # Main stylesheet
├── mediaqueries.css     # Responsive breakpoints
├── script.js            # Interactions & WordPress API fetch
├── assets/              # Images (profile pic, project screenshots)
│   ├── linkedin.png
│   ├── github.png
│   └── email.png
└── mycv (1).pdf         # CV
```

## GitHub Pages Deployment

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch** → branch `main`, folder `/ (root)`
4. Your site will be live at `https://domin-flame.github.io/<repo-name>/`

## Local dev
Just open `Portfolio.html` in a browser — no build step needed.
